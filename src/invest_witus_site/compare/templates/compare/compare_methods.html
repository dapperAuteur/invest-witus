How to read this. Each "{% if yardstick %}Same money into {{ yardstick.symbol }}{% endif %}" row is what doing nothing but buying the index fund with the same money would have given: every buy of the account, on its own day and for the same dollars, buys {% if yardstick %}{{ yardstick.symbol }}{% endif %} at that day's stored adjusted close instead (the close when a stored day has no adjusted close, as the row says), and a sell takes the same dollars out. A day with no stored price is named, never guessed. Compare its money put in, value and money-weighted return with the account's row just above: if the account's are lower, the index fund alone did better with your money over these days. {% if same_left_off %}The chart has room for six lines, so the same-money lines of {{ same_left_off|join:", " }} are in the table only.{% endif %}

Money-weighted or time-weighted? The money-weighted return counts when your money went in, so it judges the method and the timing of your deposits together; the time-weighted return leaves the deposits out, so it judges the method alone, and it is what the chart draws. Under a year, both are the change over the days shown; from a year on, both are a yearly rate.

How to read this.

  • A few months prove nothing. Over months, luck moves these lines more than any method does. Judge a method over years, and by whether you kept to it.
  • The methods buy differently. 12-1 momentum buys only its top N of your list each month; index investing buys all of it. Holding fewer symbols makes the line swing more, up and down.
  • Same cash, same amount, same list: a fair test. When the accounts start with the same money, put in the same amount each month and draw from the same symbols, the method is the one thing that differs.
  • Past results do not predict future results. This page describes what happened; it is not a forecast and not advice. Lesson coming.
